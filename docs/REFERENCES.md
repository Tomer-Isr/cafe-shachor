# Часть I. Разбор референсов

## 1. By-Kin — учебный пример №1 из нашего документа

**URL:** https://by-kin.com/
**Награды:** Awwwards SOTD + Developer Award, FWA, CSS Design Awards.
**Стек:** Next.js + GSAP + Strapi.

![By-Kin](../../../../tmp/cafe-refs/by-kin-scroll.png)

Что видно на кадре: кремовая база (≈`#f2f0eb`), логотип `'kin` оранжевым
(≈`#ff5c39`) размером в четверть экрана и обрезанный верхним краем. Меню —
четыре слова серифом с подчёркиванием, крупно (≈24 px), не мелким шрифтом
в углу. Микро-лейблы `FEATURED WORKS`, `2025`, `SAYHI@BY-KIN.COM` —
моноширинные, ~10 px, разрядка ~0.12em, цвет почти сливается с фоном.
Между шапкой и контентом — пустая треть экрана, ничем не заполненная.
Превью проектов — крошечные, 78×60 px, пронумерованы `01 / 02 / 03`.

**Что берём:**
- **Вся страница — один timeline, а не набор эффектов.** Переход собирается
  как одна GSAP-последовательность из трёх слоёв (уходящий вид, слой
  перехода, приходящий контент) с позиционным перекрытием `'<0.15'` — чтобы
  между блоками не было мёртвых кадров. Это ровно наш диагноз 1.2.
- **Один набор easing и одна шкала длительностей на весь сайт.** У них
  reveal'ы стандартизованы: `yPercent: 20`, `opacity: 0`, `ease: 'expo.out'`,
  `duration: 1`. Не «подобрать каждой анимации своё» — а три длительности и
  две кривые на всё.
- **Три типографических регистра вместо двух:** крупный сериф (меню и
  заголовки), средний гротеск (текст), моно-микрокапс с разрядкой (метки,
  годы, почта). Третий регистр стоит почти ничего и сразу убирает
  «ровный ряд заголовков», о котором написано в диагнозе 1.1.
- **Пустота как элемент, а не остаток.** Треть экрана намеренно пустая.
- Технически: анимируются только `transform` и `opacity`;
  `gsap.matchMedia()` включает урезанный путь для `prefers-reduced-motion`.

**Чего не берём:** кремовую светлую базу — мы тёмные по позиции.
Переключатель `LAYOUT 1 / 2` (у нас одиннадцать экранов одной истории,
второй раскладки для неё не существует). Меню из четырёх подчёркнутых слов —
для длинной страницы этого мало, нужен индикатор положения.

## 2. Iventions — учебный пример №2

**URL:** https://iventions.com/
**Награды:** CSS Design Awards Website of the Month, Awwwards SOTD.

![Iventions](../../../../tmp/cafe-refs/iventions-scroll.png)

Главное на кадре — не 3D, а приём с типографикой. Лавандовое пятно
(≈`#8b85e8`) органической формы ползёт по костяному фону (≈`#e9e3dd`).
Внизу — вордмарк `IVENTIONS` во всю ширину, обрезанный нижним краем.
И буквы **меняют цвет там, где по ним прошло пятно**: слева, на лаванде,
они тёмно-синие; справа, на бежевом, — бежевые. Одна и та же надпись, два
цвета, граница проходит по живому краю движущейся формы.

Выше: заголовок `Step into the Spotlight` слева, абзац из трёх строк —
справа, мельче и легче. Это не две равные колонки, это пара разного веса.

**Что берём:**
- **Готовое решение нашей задачи «текст поверх меняющегося кадра».** Не
  вуаль, не тень — типографика переключает цвет по маске фона. У нас это
  концептуально точнее любого затемнения: чёрный — условие, свет проходит
  по буквам. Механика в разделе II.7.
- **Асимметричная пара** «крупный заголовок с одной стороны / мелкий абзац
  с другой». В RTL зеркалим: заголовок справа, абзац слева.
- **Вордмарк, обрезанный краем экрана**, как якорь секции — работает и как
  масштабный контраст (1:12 к тексту), и как ориентир «это ещё та же сцена».

**Чего не берём:** цветовую пару (лаванда + кислотный лайм на пилюле MENU)
— она чужая тёмному эспрессо. И «прожектор» как рисованную кляксу: у нас
источник света настоящий, он живёт в сцене Blender, а не в CSS.

## 3. Mat Voyce — учебный пример №3, кинетическая типографика

**URL:** https://matvoyce.tv/

![Mat Voyce](../../../../tmp/cafe-refs/matvoyce-hero.png)

Вордмарк разорван: `MAT` вверху, `VOYCE` внизу, обе части обрезаны краями
экрана, контент живёт в зазоре между ними. Гарнитура — наклонный гротеск,
кегль ≈ 20 vw, цвет циан по off-white. В шапке — два двухстрочных
микроблока: «Type designer & animator, / working for brands globally.» и
«UK based / *Working globally*» (вторая строка серая). Внизу слева —
лаймовая пилюля `— SCROLL — SCROLL` с бегущей строкой вместо стрелочки.

**Что берём:**
- **Разрыв слова на верх и низ экрана с контентом в зазоре.** Для нас —
  `שחור` наверху, `יפו` внизу, между ними манифест. Одна раскладка из
  каталога, использовать один раз.
- **Двухстрочные микроблоки в шапке**: строка-факт + строка-уточнение
  приглушённым. Дешёвый способ добавить типографический слой там, где
  раньше был пустой угол. У нас: «קפה שחור, יפו / פתוח עד 23:00».
- **`SCROLL` бегущей строкой**, а не иконка-шеврон. Мелочь, но шеврон —
  это стоковое решение, а бегущая метка держит характер.
- Главный урок по кинетике: буквы тянутся и пересобираются на прокрутке,
  но **анимация никогда не блокирует чтение** — таймлайн настроен так, что
  строка успевает встать раньше, чем взгляд до неё дойдёт.

**Чего не берём:** кислотную палитру и наклонный гротеск в 20 vw — на кафе
это будет орать. И коллаж из мокапов устройств.

## 4. Vero New-York — тёмный кадр + серифная типографика, ближайший аналог

**URL:** https://verostudio.com/
**Награды:** Awwwards SOTD 08.08.2026 + Developer Award.
**Стек:** Next.js + Sanity + WebGL.

![Vero](../../../../tmp/cafe-refs/vero-hero.png)

Полнокадровое тёплое видео (оранжевый грейд). Белый дидон `VERO` по центру
верхней трети. Под ним — **одна строка смешанного набора**: италик-серифом
`Custom`, капителью с разрядкой `SCULPTURE`, италиком `of your`, капителью
`WEDDING DRESS.` Никакого затемнения на кадре нет вообще: текст стоит
ровно там, где кадр сам глухой и без деталей. Весь хром сайта — две матовые
пилюли по верхним углам: `MENU` слева, `Start your COMMISSION` справа.

**Что берём:**
- **Смешанная строка «италик + разрядка капителью»** как подзаголовок. Один
  приём даёт всю фактуру — при том, что картинок на странице нет. Это прямой
  ответ на пункт 3.3 нашего документа.
- **Правило «текст ставим туда, где кадр сам глухой»** вместо вуали на весь
  экран. Мы рендерим кадры сами — значит можем это гарантировать (см. II.7).
- **Две пилюли по углам = вся навигация**: слева вход в меню, справа —
  единственное действие. В нашем случае справа `הזמנת שולחן`.
- Матовая (не стеклянная) заливка пилюль: полупрозрачный тёплый серый без
  блюра — на тёмном кадре читается дороже, чем glassmorphism, и не ломает
  композитинг канваса на iOS.

**Чего не берём:** чистый дидон на все одиннадцать экранов — у высоко-
контрастных серифов ивритской пары почти нет, а нам нужна параллельная
система. И центрирование всего подряд.

## 5. Exo Ape — белый текст на движущемся кадре без подложки

**URL:** https://exoape.com/

![Exo Ape](../../../../tmp/cafe-refs/exoape-hero.png)

Полнокадровое видео, белый текст, ноль подложек. Порядок обратный
привычному: сначала **абзац** из трёх строк среднего кегля (≈52 знака в
строке), а под ним — **гигантское слово**, обрезанное нижним краем экрана.
Мелкое сверху, огромное снизу. Подсказка `Scroll to explore` — призраком
справа внизу, opacity ≈ 0.35.

**Что берём:**
- **Обратная иерархия** «мелкий абзац сверху → гигантское слово снизу с
  обрезкой». Это раскладка, которой у нас сейчас нет ни на одном из
  одиннадцати экранов, и она сразу даёт масштабный контраст.
- **Тонкий гротеск работает поверх видео**, если кадр отгрейдирован под
  текст: у них зона под абзацем — ровное небо без деталей.
- Призрачная подсказка скролла на очень низкой непрозрачности — она есть,
  но не участвует в композиции.

**Чего не берём:** отсутствие подложки как догму. У них кадр почти
статичный и стабильный по яркости; у нас кадр меняется на скрабе, значит
нужна страховка на худший кадр ленты, а не на первый.

## 6. Igloo Inc — самый близкий аналог по конструкции

**URL:** https://igloo.inc/

![Igloo hero](../../../../tmp/cafe-refs/igloo-hero.png)

![Igloo — аннотации на объекте](../../../../tmp/cafe-refs/igloo-scroll.png)

Полнокадровая 3D-сцена, ноль панелей, ноль карточек. Весь текст —
моноширинный, мелкий, разложен по углам: логотип и под ним `// Copyright ©
2026`, манифест справа вверху **выключен по правому краю**, внизу слева
`Scroll down to discover.` и тумблер `Sound: Off`.

Второй кадр — то, ради чего стоит смотреть: **диегетические подписи прямо
на объекте**. `PORTFOLIO_CO_03 / ABSTRACT` с волосяной выноской к грани,
`TEMP 26.60 / -03.00` — приборный отсчёт, `D 06.28.2024 / CLICK TO EXPLORE`
с линией-указателем. Текст не лежит поверх сцены — он к ней прикреплён.

**Что берём:**
- **Моно-аннотации по углам вместо UI-панелей.** Ровно то, чего нам не
  хватает: сейчас у нас правая колонка на всех одиннадцати экранах, а можно
  вообще без колонки.
- **Диегетические подписи с выносками.** Для кофе это готовый словарь:
  `92°C`, `18 g / 36 g`, `28 sec`, `Yirgacheffe · 1900 m` — прикреплённые
  волосяной линией к чашке в кадре. Это одновременно решает проблему
  «нет арт-дирекции»: подписи становятся частью изображения.
- **Выключка манифеста по правому краю.** У них это стилистический жест —
  у нас родная выключка иврита. То есть RTL здесь не проблема, а
  преимущество: мы получаем этот приём бесплатно.
- **Тумблер звука** как единственный постоянный переключатель внизу слева.

**Чего не берём:** холодную серебристо-стальную гамму. И технарскую лексику
(`// Copyright`, `PORTFOLIO_CO_03`) — форму приёма берём, словарь нет: у нас
кофейня, а не крипто-проект.

## 7. Active Theory — минимум хрома на чёрном

**URL:** https://activetheory.net/

![Active Theory](../../../../tmp/cafe-refs/activetheory-hero.png)

Чистый чёрный. Весь интерфейс — одна матовая пилюля справа вверху:
`WORK ——— CONTACT`, два слова, между ними волосяная линия вместо слэша.
По краю пилюли — мягкое свечение, границы как таковой нет.

**Что берём:**
- **Навигация как один объект**, а не набор ссылок. Разделитель —
  волосяная линия, не `/` и не `·`.
- **Свечение по краю вместо `border`** — на тёмном фоне рамка в 1 px
  выглядит нарисованной, а мягкий световой кант — как подсвеченный предмет.
  Это же согласуется со сценой: у нас источник света в кадре.
- Моноширинный набор в пилюле с разрядкой — читается как маркировка
  оборудования, а не как меню сайта.

**Чего не берём:** полное отсутствие ориентира. У них короткая страница,
у нас одиннадцать экранов — одной пилюли мало.

## 8. Basement Studio — тёмная 3D-сцена с полноценным меню

**URL:** https://basement.studio/

![Basement](../../../../tmp/cafe-refs/basement-hero.png)

## 9. Obys Agency — три решения навигации в одном кадре

**URL:** https://obys.agency/

![Obys](../../../../tmp/cafe-refs/obys-hero.png)

Сразу три приёма ориентации:
1. **Вертикальный индекс** всех проектов в левом поле мелким кеглем: все
   строки серые, активная (`Eminente`) — чёрная. Никакой полоски прогресса.
2. **Переключатель раскладки** `Vertical, Horizontal, Grid` в левом нижнем
   углу, активный — подчёркнут.
3. **Часы с местным временем** `CEST 10:09 PM` прямо в шапке.

Плюс: активный элемент помечен **скобками `(  )`** по бокам — вместо рамки
или подсветки.

**Что берём:**
- **Индекс-список секций, где положение показано цветом активной строки.**
  Для нас это идеально: пять названий блоков мелким кеглем в поле, все
  приглушены, текущий — акцентом. Это дешевле полоски прогресса, и это
  одновременно оглавление и «где я».
- **Часы с местным временем.** Для кофейни это не декор, а информация:
  `22:41 · פתוח עד 23:00`. Тот же элемент годится и в финал (см. II.6).
- **Скобки вместо рамки** как маркер фокуса и hover — типографический
  приём вместо графического.

**Чего не берём:** три способа навигации одновременно — это портфолио
студии, им можно. И чёрно-белую гамму.

## 10. Studio Freight — работа с пустотой

**URL:** https://studiofreight.com/

![Studio Freight](../../../../tmp/cafe-refs/studiofreight-hero.png)

Композиция «полая середина»: превью проектов прижаты к периметру экрана

## 11. Locomotive — цвет текста на тёмном

**URL:** https://locomotive.ca/en

![Locomotive](../../../../tmp/cafe-refs/locomotive-hero.png)

Тёмный кадр в тяжёлом красном грейде. Заголовок
`Locomotive® / Digital-first Design Agency✳` набран **тонким серифом в
бледно-циановом**, не белым. Меню — список через запятую, где активный
раздел выделен **цветом** (`Careers` циановый, остальные белые). Слева от
заголовка — моно-бейдж в рамке: `OPS | DES / DEV`.

**Что берём:**
- **Текст на тёмном — не чистый `#fff`.** Уведённый в холод (у них) или в
  тепло (наш случай, `#f2ece4`) цвет перестаёт выглядеть наклеенным поверх
  фотографии и начинает читаться как часть кадра.

## II.1. Типографика

### Пары, которые реально работают на тёмном

**Пара A: высококонтрастный сериф-дисплей + нейтральный гротеск.**
Vero, Locomotive. Даёт «дорого» мгновенно. Условие — сериф только крупно
(от ≈56 px): на тёмном фоне тонкие засечки страдают от halation (светлые
штрихи «разъедаются» в тёмный фон) и в мелком кегле разваливаются.

**Пара B: гротеск-дисплей + моноширинный для меток.**
Igloo, Basement, By-Kin, Locomotive. Моно даёт «приборный» слой без
третьего смыслового уровня — метки, цифры, координаты, время. На тёмном
это самый устойчивый вариант.

**Пара C (наш случай): три регистра.** Дисплей (ивритский сериф) — текст
(гротеск) — метки (латинский моно). Больше трёх гарнитур не брать.

### Правила набора светлым по тёмному

| Параметр | Что делать | Почему |
|---|---|---|
| Вес корпуса | не ниже 400, лучше 450–500 | тонкие начертания на тёмном «испаряются» |
| Трекинг корпуса | +0.005…+0.01em к светлой теме | буквы визуально слипаются |
| Интерлиньяж | +0.05 к светлой теме | текст на тёмном требует больше воздуха |
| Кегль корпуса | +1–2 px к светлой теме | оптическая компенсация |
| Цвет текста | не `#fff`, а `#f2ece4` (тёплый уход 4–8%) | белый на кадре выглядит наклеенным (Locomotive) |
| Контраст H1 : подпись | не меньше 1:8 | из DESIGN-DIRECTION 3.2 |
| Цены | `font-variant-numeric: tabular-nums` | одинаковая ширина знака в колонке |
| Длина строки | 45–75 знаков | у нас местами шире |

**Рекомендация для Shachor:**
заголовки — ивритский высококонтрастный сериф-дисплей (**Lilith** или
**Karma**; бесплатный ход — **Suez One** на одно-два гигантских слова +
**Frank Ruhl Libre** на остальные заголовки);

проблема, а решение: метки, цифры, время и координаты **намеренно остаются
латиницей во всех трёх локалях** — как `חשבונית מס` в проекте визитки,
только наоборот.

**Отдельно про метрику иврита.** У иврита нет надстрочных и подстрочных
элементов, поэтому строка визуально плотнее латинской при том же кегле.
Практически: интерлиньяж ивритских заголовков ставить на 0.05–0.1 больше
латинского, а кегль — на 5–8% меньше при том же оптическом размере.
Проверять на живом тексте, не на «лорем ипсум» — иврит без пунктуации
ведёт себя иначе.

| a | **Полный кадр + аннотации по углам** — нулевая колонка, текст живёт в полях | Igloo | сцена без единой панели, четыре угла с моно-подписями |
| b | **Обратная иерархия** — мелкий абзац сверху, гигантское слово снизу с обрезкой | Exo Ape | манифест → `שחור` под обрез |
| c | **Разрыв вордмарка** верх/низ, контент в зазоре | Mat Voyce | `שחור` вверху, `יפו` внизу, между ними одна фраза |
| d | **Асимметричная пара** — крупный заголовок с одной стороны, мелкий абзац с другой, разного веса | Iventions | в RTL: заголовок справа, абзац слева |
| e | **Полая середина** — периметр занят, центр пуст, в центре одна строка | Studio Freight | моно-метки по периметру, фраза манифеста в центре |
| f | **Вордмарк, обрезанный краем, поверх которого проходит фон и переключает цвет букв** | Iventions | свет из сцены проходит по слову — см. II.7 |
| g | **Лесенка весов одного слова** | Hafontia | `שחור` тремя весами по мере наезда камеры |
| h | **Стена слов** — список набран сам собой, разными кеглями, заполняет кадр | Hafontia | меню позиций вместо таблицы; цены уходят в моно-подписи |
| i | **Билингвальный стек** — иврит выключен вправо сверху, латиница влево снизу | Fontef | там, где хотим показать две письменности сразу |
| j | **Строка-микс** — италик + разрядка капителью в одной строке | Vero | подзаголовки блоков |
| k | **Сцена в рамке с полями + кроп-марки `+`** | Lusion | смена плана после серии полнокадровых |
| l | **Цитата на весь экран** — одна фраза, ничего больше, крупный тонкий сериф | Locomotive (по типу набора) | один раз за страницу, в самом тихом месте плёнки |
| m | **Вертикальный текст** | — | ровно один раз, как ось секции. ⚠️ в RTL `writing-mode: vertical-rl` для иврита ведёт себя неочевидно — проверять отдельно, это грабли |
| n | **Двухстрочные микроблоки в шапке** — строка-факт + строка-уточнение приглушённым | Mat Voyce | `קפה שחור, יפו / פתוח עד 23:00` |

**Правило распределения.** Одиннадцать экранов ≠ одиннадцать раскладок.
Взять 5–6 приёмов и повторить их с интервалом — тогда повтор читается как
ритм, а не как лень. Крупные (a, b, e, f) не ставить подряд: между двумя
масштабными нужен тихий.

## II.3. Хореография

### Как у хороших сайтов связаны фон и текст

Три уровня, снизу вверх:

**1. Один timeline на всю страницу.** У By-Kin вся страница — одна
GSAP-последовательность, к которой подцеплено всё: и скраб, и reveal'ы, и
переходы. Не «эффект скролла» + «эффект появления», живущие рядом. Это
буквально диагноз 1.2 нашего документа.

**2. Один набор кривых и длительностей.** У By-Kin: `ease: 'expo.out'`,
`duration: 1`, `yPercent: 20`, `opacity: 0` — и всё. Нам по DESIGN-DIRECTION
нужно три длительности и две кривые, зафиксированные токенами.

**3. Скорость появления текста берётся из состояния камеры.**
Сейчас у нас всегда 0.85 с / шаг 0.085 с независимо от того, стоит камера
или летит. Должно быть:

| Состояние камеры в блоке | Выход текста | Шаг между строками |
|---|---|---|
| стоит (крупный план чашки) | 0.9–1.2 с | 0.10 с |
| медленный дрейф | 0.7 с | 0.07 с |
| облёт / быстрый пролёт | 0.4–0.5 с | 0.04 с |

### Пять приёмов передачи эстафеты между секциями

1. **Перехлёст.** Уходящий блок начинает уводиться, и следующий стартует за
   15% до конца предыдущего (`position: '<0.15'` у By-Kin). Мёртвых кадров
   между блоками не остаётся. Самый дешёвый и самый заметный по эффекту.
2. **Общий носитель.** Переход происходит **в буквах**, а не между блоками:
   фон проезжает по типографике и переключает её цвет (Iventions). Эстафету
   передаёт не анимация, а сама сцена.
3. **Наследование скорости.** Скорость скролла (`ScrollTrigger.getVelocity()`)
   подмешивается в лёгкий skew или blur появляющегося текста. Тогда движение
   фона и движение текста читаются как одна инерция, а не два механизма.
4. **Пин + вычитание.** Секция пиннится, кадр продолжает идти, текст
   меняется на месте. Камера не останавливается вместе с текстом — это
   ровно то, что отличает «хореографию» от «блоков с анимацией».
5. **Пауза как элемент.** Перед сменой блока — 300–400 мс, где замирает
   всё, кроме кадра. Тишина в монтаже. Без неё одиннадцать экранов
   превращаются в непрерывный поток без акцентов.

**Ограничения (не обсуждаются):** только `transform` и `opacity`;
`gsap.matchMedia()` на `prefers-reduced-motion`; замер fps на реальном
телефоне, не в headless.

## II.4. Вход (прелоадер)

Нам это нужно не как украшение, а технически: страница везёт 6–14 МБ кадров.

### Механики, которые берём

**Счётчик 0→100, привязанный к реальной загрузке.** Не таймер. Считаем
декодированные кадры (`img.decode()` по мере препроцессинга) — тогда цифра
честная. Стандартная уловка: идти по факту до 99, а последний процент
отдать после того, как первый кадр готов к отрисовке.

**Гейт вместо спиннера** (Unseen Studio). Осмысленный экран: имя, одна
фраза, одна пилюля `כניסה` — и ниже, тише, вторая ссылка
`כניסה ללא אנימציה`. Это честный ответ сразу на две вещи: на вес страницы и
на `prefers-reduced-motion`. Пока читается фраза — догружается первый пакет.

**Раскрытие сцены, а не растворение.** Занавес уезжает, и за ним первый
кадр уже идёт, камера уже движется. Тогда вход — начало истории, а не
пауза перед ней.

### Под наши 6–14 МБ — конкретно

- До входа грузить **только первый кадр + первые ~20% ленты**, остальное
  догружать по мере скролла с окном опережения.
- Счётчик показывает прогресс **первого пакета**, а не всей ленты — иначе
  вход растянется на 20 секунд и всё испортит.
- Если пакет пришёл быстрее 800 мс — счётчик всё равно доигрывает до 100 за
  ~600 мс: мгновенный проскок читается как сбой.

### Что выглядит дёшево

- Спиннер любой формы.
- Прогресс-бар с фиксированной длительностью при мгновенной загрузке.
- Счётчик, доскакавший до 100 и висящий там секунду.
- Логотип, который «пульсирует» на месте.

## II.5. Навигация на длинной странице

Одиннадцать экранов, пять смысловых блоков. Отранжировано под нас.

| Решение | Где взято | Оценка для нас |
|---|---|---|
| **Индекс-список секций**: пять названий мелким кеглем в поле, все приглушены, текущий — акцентом | Obys | **лучший вариант.** Дешевле полоски прогресса, и это одновременно оглавление и «где я». В RTL уходит в правое поле |
| **Липкая подшапка с якорями, появляющаяся после первого экрана**: имя слева — якоря — одно действие пилюлей | Apple | хороший второй вариант, если хотим кнопку брони всегда на виду |
| **Одна пилюля из двух слов через волосяную линию** | Active Theory | красиво, но на одиннадцати экранах мало |
| **Счётчики надстрочным в пунктах** (`תפריט⁽¹⁴⁾`) | Basement | добавка к любому из первых двух |
| **Меню списком через запятую**, текущий помечен точкой | Studio Freight | подходит; в RTL работает так же |
| **Лента вкладок** под шапкой | Fontef | хуже: наши блоки сюжетные, а не равнозначные |
| **Часы с местным временем + статус** | Obys | берём обязательно: для кофейни `22:41 · פתוח עד 23:00` — не декор, а информация |

### Переключатель языков

**Правильное место — утилитарная зона навигации, словом на своём языке,
без флагов:** `עברית · RU · EN` (Fontef). Флаг обозначает страну, а не
язык, и для иврита это особенно неверно.

**Второй допустимый вариант** — парный/тройной тумблер внизу по центру
(по типу `HUMAN | MACHINE` у Basement), если решим полностью очистить шапку.
Там же уже стоит тумблер звука у Igloo — эта зона под переключатели.

**Чего не делать:** выпадающий `<select>`; иконка глобуса; флажок рядом со
словом (AlefAlefAlef — выглядит как магазин); переключатель, сбрасывающий
позицию скролла — у нас уже записано стандартом, что смена языка держит
секцию.

## II.6. Финал

Сейчас страница просто заканчивается подвалом. Варианты финального жеста,
от сильного к слабому:

1. **Обратный жест.** Последний экран возвращает первый кадр: камера
   отъезжает от чашки обратно на общий план, круг замыкается. Дешевле всего
   в реализации — та же лента, обратный скраб — и сильнее всего по
   ощущению. Для страницы, построенной на движении камеры, это единственный
   финал, который вытекает из конструкции, а не приделан к ней.
2. **Крупная контактная строка вместо подвала.** Имя, улица, часы, телефон
   — одной типографической композицией на весь экран, тем же дисплейным
   шрифтом, что и заголовки. Подвал перестаёт быть служебкой и становится
   последним разворотом.
3. **Часы со статусом** (Obys): `сейчас 22:41 — открыто до 23:00`. Для кафе
   это и есть содержательный финал: человек досмотрел — и получил ответ на
   единственный вопрос, который у него остался.
4. **Одна базовая линия внизу** (Studio Freight): соцсети слева, имя по
   центру, `©` справа. Три точки выключки на одной строке, больше ничего.

Оптимально — совместить 1 + 2 + 3: камера отъезжает, поверх отъезда
выходит контактная композиция, в ней живут часы со статусом, под всем —
одна строка (4).

**Чего не делать:** бегущей строки `LET'S TALK LET'S TALK` — приём
выработан до дыр. Гигантской кнопки, ведущей в никуда. «Наверх ↑» как
финального жеста.

## II.7. Текст поверх движущегося фона

Наш самый острый пункт: кадр под текстом меняется на скрабе, и на светлых
участках текст проваливается.

### Что даёт премиальный результат

**1. Грейд под текст в самом пререндере. Главный инструмент.**
Мы рендерим кадры сами — значит можем гарантировать, что в зоне будущего
текста кадр глухой и без деталей: виньетка, уход в тень, мягкий градиент,
принудительный расфокус фона. Стоит ноль по рантайму, работает одинаково на
всех устройствах, не зависит от того, какой кадр сейчас под текстом.
Так решают Vero (текст стоит там, где кадр глухой), Exo Ape (ровное небо
под абзацем) и Pangram Pangram (десатурация + расфокус в зоне слова).
**Это первое, что надо сделать, и половина остальных приёмов после этого не
понадобится.**

**2. Скрим-градиент, а не заливка.**
```css
background: linear-gradient(to top, rgba(0,0,0,.72), transparent 60%);
```
Привязан к тому краю, где стоит текст. Измеримо (контраст можно посчитать),
не мутит кадр целиком, WCAG AA достижим. Рабочая страховка поверх п.1.

**3. Переключение цвета типографики по маске фона** (Iventions).
Там, где по букве проходит светлое пятно, буква становится тёмной.
Реализуется `mix-blend-mode: difference` (или `exclusion`) на текстовом
слое **внутри контейнера с `isolation: isolate`** — иначе блендинг уйдёт в
весь стек ниже, включая фон страницы. Самый дорогой на вид приём и
концептуально наш: «чёрный — не цвет, а условие». Ограничение: контраст на
нём не гарантируется формально, поэтому — только для крупного дисплейного
набора (вордмарк, одно слово), никогда для корпуса и цен.

**4. Локальная подложка под конкретную строку**, а не под блок. Узкая
плашка по ширине строки, opacity 0.55–0.7, без скруглений. Для цен, часов
работы, адреса — там, где важна не красота, а прочтение с одного взгляда.

**5. Оптический вес вместо эффектов.** Поднять вес корпуса на ступень и
кегль на 1–2 px. Часто закрывает вопрос без единого дополнительного слоя.

### Что выглядит дёшево

- `text-shadow: 0 2px 8px rgba(0,0,0,.8)` — «наклейка», читается как
  2012 год. Допустим только волосяной контактный `0 1px 0 rgba(0,0,0,.35)`,
  и то не везде.
- Затемнение всего кадра на 40–50% — убивает сцену, ради которой всё
  делалось.
- `backdrop-filter: blur()` поверх канваса — дорого по GPU и **ломает
  композитинг канваса на iOS** (уже записано в наших граблях).
- `-webkit-text-stroke` на корпусе — игровой UI.
- Полупрозрачная «стеклянная карточка» под текстовым блоком — это и есть
  та самая AI-генерик-эстетика, которую проект запретил отдельным пунктом.

### Как проверять (не глазами)

Контраст мерить не на одном кадре, а на **выборке**: взять каждый 10-й кадр
ленты, посчитать среднюю яркость прямоугольника под каждым текстовым
блоком, найти худший кадр и мерить по нему. Если худший кадр не проходит
4.5:1 — правится **пререндер** (п.1), а не CSS. Это скрипт на полчаса, и он
закрывает пункт 3.6 нашего документа «контраст измерить, а не смотреть».

# Часть III. Что из этого идёт в решения

Короткая сводка, чтобы не перечитывать всё.

**Типографика.** Три регистра: ивритский сериф-дисплей (Lilith / Karma;
бесплатный ход — Suez One + Frank Ruhl Libre) → гротеск для корпуса
(Miriam Libre / Ella Sans) → латинский моно для меток и цифр во всех трёх
локалях. Текст `#f2ece4`, не белый. Корпус ≥ 400, трекинг +0.01em,
интерлиньяж +0.05. Иврит: интерлиньяж +0.05…0.1, кегль −5…8%.

**Раскладки.** Взять 5–6 приёмов из каталога II.2 и разложить их по
одиннадцати экранам с интервалом. Обязательно: полный кадр с
аннотациями (a), обратная иерархия (b), полая середина (e), стена слов для
меню (h), строка-микс для подзаголовков (j).

**Хореография.** Один GSAP timeline на всю страницу. Три длительности, две
кривые токенами. Скорость выхода текста берётся из состояния камеры.
Переходы — перехлёстом `'<0.15'` + пауза 300–400 мс перед сменой блока.

**Вход.** Гейт с честным счётчиком первого пакета кадров + вторая тихая
ссылка «без анимации». Раскрытие сцены на уже идущем кадре.

**Навигация.** Индекс-список из пяти блоков в правом поле, активный —
акцентом. Часы со статусом «открыто до». Языки — словом
(`עברית · RU · EN`) в утилитарной зоне, без флагов.

**Финал.** Обратный отъезд камеры + контактная композиция дисплейным
шрифтом + часы со статусом + одна базовая линия внизу.

**Текст на кадре.** Сначала грейд в Blender под каждую текстовую зону,
потом скрим-градиент как страховка, `mix-blend-mode` — только на
дисплейном слове. Проверка — скриптом по выборке кадров, не глазами.
