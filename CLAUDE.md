# Shachor / שחור — демо-кафе с 3D-героем

Демо-концепт кофейни в Яффо для портфолио визитки `iukhvidov`. Вымышленный бренд.
Задача демо — доказать уровень исполнения, а не продавать кофе.

Контент-источник: `D:\Claude\projects\iukhvidov\plans\cafe-demo\` (легенда, 29 позиций, копирайт).
Приёмы: `D:\Claude\docs\3d-web-playbook.md` + `web-design-playbook.md`.

## Стек
Vite + React 19 + TS · Tailwind v4. Локали HE (default, RTL) / RU / EN.
Деплой — статика на GitHub Pages (из ветки `gh-pages`).

## Герой — пререндер, а не реалтайм
Сцена считается в Blender/Cycles (`render/scene.py`) и крутится прокруткой как
плёнка. Реалтайм на R3F признан тупиком и снят; пакеты three/fiber ещё висят в
зависимостях, но в сборку не идут.

Каждый кадр приходит парой: картинка (`public/film` 1100 px для телефона,
`public/film-hd` 1600 px для десктопа) и служебная карта `public/film-aux` —
в красном канале глубина, в зелёном номер предмета. На ней держится вся
реакция на курсор: параллакс по глубине, свет по контуру предмета, пар над
чашкой, волна от нажатия. Подробности и грабли — `docs/STATUS.md`.

## Позиция бренда (из неё выводится всё)

**«Здесь всё на виду — включая цену и дату».** Выбрана Томером, см. `docs/MARKET.md` §7.
Практически: ничего не спрятано за кликом — ни аккордеонов с ценами, ни «показать ещё»,
ни модалок, ни табов-фильтров в меню. Сцена — доказательство, а не украшение: камера
показывает то же, что увидит гость. Подчинённый принцип — «чёрный не цвет, а условие»:
тёмное это базовое состояние холста, свет появляется только там, где что-то происходит.

## UI Kit — выжимка

🔴 **Источник истины — [`docs/DESIGN-SYSTEM.md`](docs/DESIGN-SYSTEM.md).** Значения
меняются там, здесь только шпаргалка. Перед версткой любого экрана читать документ
целиком: палитра с посчитанным контрастом, пять уровней типошкалы под три письменности,
каталог раскладок по блокам, motion-токены, карманы под текст, состояния, reduce-motion.

```
--ink       #0a0908   фон и всё, что за кадром
--soot      #15120f   промежуточный: гейт, матовые пилюли, поля
--pitch     #060504   скримы и гало вокруг фокуса
--fg        #ece6dc   текст (16.03:1 на ink)
--fg-dim    #c9c0b3   корпус поверх живого кадра (11.06:1)
--muted     #93897c   метки — только на ink/soot (5.79:1)
--line-ui   rgba(236,230,220,.48)   границы кнопок/полей — несут смысл (4.41:1)
--line-hair rgba(236,230,220,.16)   разделители списка — декор
--accent    #c8703a   обжаренная медь (+hi #d67f47, +lo #b8642f)
```

- **Бюджет акцента — пять появлений на всю страницу**, максимум одно в поле зрения.
  Акцент никогда не текст поверх живого кадра и никогда не подложка под светлый текст
  (`--fg` на `--accent` = 2.90:1 — запрещено).
- **Типошкала 5 уровней**, контраст display : caption ≥ 8:1 на всех ширинах.
  Три регистра: Suez One / Frank Ruhl Libre / Cormorant Garamond (RU) — дисплей;
  Miriam Libre / Commissioner (RU) — корпус; IBM Plex Mono — метки, цифры и цены
  **латиницей во всех трёх локалях**. Heebo, Assistant, Rubik, Almoni, Playfair
  запрещены как дефолт. Иврит: −5…6% кегль, +0.06 интерлиньяж.
- **Motion:** три длительности `180 / 450 / 900 ms`, две кривые. Скорость выхода
  текста берётся из состояния камеры: `dur = 900 − v·450`, `stagger = dur/9`.
- **Spacing** — шкала 4/8. Радиусы: 0 (камень и бетон, не скругления).
- **Текст на кадре:** читаемость правится грейдом в Blender, не CSS. `backdrop-filter`
  и многослойный `text-shadow` запрещены. Проверка — `render/check_contrast.py`
  по выборке кадров с замером p95 по худшему.
- Цена всегда `<Price>` → `dir="ltr"`, формат `12 ₪`, моно, табличные цифры.

## Что НЕ делать
- Не симулировать жидкость — это заявленный потолок проекта.
- Не подключать платные API/ключи. Ассеты только CC0 (Poly Haven HDRI лежит в `public/hdr`).
- Не показывать fake-success брони — бронь заканчивается в WhatsApp.
- Не поднимать перф-планку до PSI 90+: решение Томера — зрелищность важнее (ориентир 70–80).
  Но 60fps на телефоне, пауза сцены, reduced-motion и фолбэк без WebGL — обязательны.
